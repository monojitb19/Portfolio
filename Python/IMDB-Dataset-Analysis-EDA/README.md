
<h1>🎬 IMDb Movies Data Analysis</h1>

<p>
A data-driven exploration of how ratings, budgets, genres, and popularity influence movie performance.  
This project uses <strong>Python</strong>, <strong>Pandas</strong>, <strong>NumPy</strong>, <strong>Matplotlib</strong>, and <strong>Seaborn</strong> to clean the data, analyze trends, and uncover insights from the IMDb movies dataset.
</p>

<h2> Project Overview</h2>

<p>
The goal of this project is to identify patterns that shape movie success.  
The analysis focuses on:
</p>

<ul>
  <li><strong>Ratings</strong> — IMDb scores, user reviews, and critic reviews</li>
  <li><strong>Budgets & Revenue</strong> — financial performance and ROI patterns</li>
  <li><strong>Genres</strong> — frequency, combinations, and earning potential</li>
  <li><strong>Popularity</strong> — social signals such as Facebook likes</li>
  <li><strong>Countries & Directors</strong> — contribution to commercial performance</li>
</ul>

<p>
The workflow follows a complete data analysis pipeline:
</p>

<ul>
  <li><strong>Data Cleaning & Preparation</strong> — handling missing values, fixing types, removing duplicates</li>
  <li><strong>Exploratory Data Analysis (EDA)</strong> — distributions, correlations, bivariate and multivariate patterns</li>
  <li><strong>Business Insights (Top-N Analysis)</strong> — top movies, genres, countries, and directors</li>
</ul>

<hr>

<h2> Key Insights</h2>

<ul>
  <li>Higher budgets generally correlate with higher gross revenue, but with large variability</li>
  <li>Drama and Comedy are the most common genres, while Action and Adventure dominate revenue</li>
  <li>IMDb scores show moderate relationships with duration and user engagement</li>
  <li>USA and UK lead in total movie output and earnings</li>
  <li>Top directors contribute disproportionately to total box-office revenue</li>
</ul>
