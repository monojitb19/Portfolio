# Bank Marketing SQL & Python Analysis

This project analyzes the **Bank Marketing Dataset** using **PostgreSQL (SQL)** and **Python (Jupyter Notebook)**.  
The goal is to identify customer groups most likely to subscribe to a **term deposit**, and understand which attributes contribute to higher conversion rates.

---

## Highlights

### 🔹 SQL Analysis
- Clean SQL schema creation + CSV import
- Exploratory analysis: counts, summaries, distributions
- Conversion rate breakdown: job, education, marital status, contact type
- Advanced SQL techniques:
  - **CTEs**
  - **Window functions**
  - **Segmentation (age groups, campaign performance)**
  - **Behavioral patterns of subscribers vs non-subscribers**

### 🔹 Python Support
- Visualizations validating SQL findings:
  - Age distribution histogram  
  - Conversion rate by job  
  - Subscription comparison (yes vs no)  
  - Age-group segmentation analysis  

---

## Key Insights
- Occupations like **students** and **retired** show higher conversion rates  
- **Cellular contact** performs significantly better than telephone  
- Conversion varies across **education levels** and **age groups** 
- Younger and middle-aged customers show distinct behavior patterns in subscription outcomes
- Most customers in the dataset do not subscribe, showing a strong class imbalance toward “no”.
